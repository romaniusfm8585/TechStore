# Use-case модель програмного продукту

## Загальна інформація

**Назва продукту:** TechStore (інтернет-магазин комп'ютерної техніки та комплектуючих).  
**Основний актор:** Покупець (користувач, який шукає, обирає та замовляє техніку).  
**Додаткові актори:** Відсутні (в першій версії MVP розглядається сценарій взаємодії покупця з онлайн-магазином).  

---

## Опис акторів

* **Покупець (основний актор):** Здійснює перегляд каталогу товарів, додає товари до кошика, надсилає форму зворотного зв'язку для отримання консультації, а також порівнює товари та переглядає їхні технічні характеристики.

---

## Основні випадки використання

1. **UC1. Переглянути каталог товарів** (пов'язано з FR-01, US-01).
2. **UC2. Додати товар до кошика** (пов'язано з FR-02, US-02).
3. **UC3. Надіслати форму зворотного зв'язку** (пов'язано з FR-05, US-03).
4. **UC4. Порівняти товари** (пов'язано з FR-03, US-04).
5. **UC5. Переглянути деталі товару** (пов'язано з FR-04, US-05).
